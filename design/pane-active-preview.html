窗格激活样式 · 六个候选方案

现状是 方案 0：激活窗格 = 1px 染色边框 + 3px 外描边（.np-pane-active）， 整圈约 4px 的强调环——醒目但视觉重量大，且圆角处叠加后显得更厚。
每张卡片是同一个双窗格片段：点击任意窗格可切换激活态，直接对比各方案的切换观感。取值全部来自 np-* token。

现状对照方案 0 · 染色粗描边1px 染色边框 + 3px outline 外描边
醒目、语义直白；outline 画在外侧，窗格内部尺寸零变化
视觉重量大；圆角处 4px 线叠加显厚；与分隔条指示线、拖放高亮同时出现时"线太多"
index.css 现状：.np-pane-active { border-color + outline: 3px }
推荐候选方案 1 · 细描边 + 柔光1px accent 边框 + 柔和外晕，无硬边加粗
保留"边框 = 激活"的直觉，视觉重量约为现状一半；柔光沿圆角自然扩散，角落不再"叠厚"
深色主题下柔光对比略弱，需按主题调外晕浓度；与拖放高亮（内描边）要错开色阶
.np-pane-active 改为 border-color: var(--np-accent)，outline 换 box-shadow 两层（1px 22% + 14px 30%）
推荐候选方案 2 · 导航栏染色激活落在窗格头部（导航栏 + 标签），边框只轻微染
"导航/地址栏属于本窗格"的语义刚好被染色强调；列表区零干扰；浏览器活动标签的既有直觉
极窄窗格的导航栏面积小、辨识度下降；染色层与导航栏 hairline 底边需协调
.np-pane-active .np-nav { background: mix(accent 9%, surface) } + 导航图标转 accent
哲学契合方案 3 · 非活动降维tmux 式：不点亮活动格，而是给非活动格盖一层灰纱
最贴合"tmux 式自由分割"的产品定位；窗格越多对比越强（10 格时最明显）；活动窗格完全无装饰
非活动格里的选中高亮、文件类型色也一起变灰，扫读性下降；明暗主题要分别调纱的浓度
.np-pane:not(.np-pane-active)::after { background: mix(bg 52%, transparent) }，pointer-events:none
最安静方案 4 · 背景微差非活动格底色掺入画布灰，活动格纯白 + 边框加深，全程无彩色
整窗只有"选中行 + 文件类型色"有颜色，层次最干净；暗色主题同样成立
反馈最弱，新用户可能找不到焦点窗格；低对比屏幕上边框微差不可辨
非活动 .np-pane { background: mix(surface 55%, bg) }；活动格 surface + 边框色加深一档
实现最简方案 5 · 顶边强调条顶边 3px accent 色条，左右底边保持中性 1px
IDE / 终端用户最熟悉的"活动标签"语言；只碰顶边直线，完全避开左右圆角的加粗问题
上下分割布局中，上格底边与下格色条只隔一条沟槽，需实测是否打架
.np-pane-active::before { position:absolute; top:0; height:3px; background:accent }（绝对定位，零布局位移）
功能联动方案 6 · 窗格编号徽章右上角编号徽章 = Ctrl+1..9 的 DFS 序号，激活时点亮
把激活指示和"Ctrl+数字聚焦第 N 窗格"快捷键合为一体，可发现性最好；非激活格保留淡编号，快捷键随时可见
角落元素要与导航按钮、标签条错位；.np-pane 有 overflow:hidden，实际落地需放内部或调整裁剪
徽章绝对定位 top:6px right:8px；非激活 = 灰底淡字，激活 = accent 底 + accent-fg 字，配 1px 染色边框
对比建议：方案 1 / 5 适合做默认（改动小、不打架）；方案 3 最有产品个性，适合做成设置项； 方案 6 可与任意方案叠加（编号徽章本身不占用边框语义）。
本页为静态设计稿，交互仅"点击切换激活 + 主题切换"；落地时取值须回到 src/index.css 的 np-* token。
