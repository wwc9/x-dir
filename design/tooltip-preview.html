按钮悬浮提示（Tooltip）· 三套方案预览

2026-10-21 · 现状 = 浏览器原生 title（约 1s 才出、样式不可控、快捷键无键帽质感）；三案均为自绘全局委托式 Tooltip，可直接悬停体验延迟与动效。快捷键取自 lib/shortcuts.ts 清单。

实现思路（定案后）：全局单例 —— 监听 mouseover/mouseout/focusin/focusout，读 data-tip + data-kbd 属性渲染唯一浮层，不用给每个按钮包组件；title 属性移除（避免双提示）。 定位 = 按钮下方居中、贴边自动上翻、视口内钳制；Esc / 滚动 / 拖拽即隐。 窗口顶缘已有 np-topline-cover 盖板，portal 固定层 glitch 家族问题已兜住。
方案 A

墨面速显（深色胶囊 + 半透明键帽）

延迟 250ms（连续切换不同按钮时立即出）· 动效 120ms 上浮 4px + 淡入 · 定位 钮下居中，贴底上翻 · 取舍：对比度最高、全局一眼可辨，VSCode/Linear 同款心智；代价是深底白字与浅色卡片语言略有反差（但提示本就该"跳"出来）。

方案 B

卡片键帽（surface 卡片，与应用浮层语言同源）

延迟 300ms · 动效 140ms 淡入 + 轻微缩放（0.96 → 1）· 定位 钮下居中，贴底上翻 · 取舍：与菜单/弹层一张"脸"（surface 底 + 发丝线 ring + np 阴影），键帽用 surface-2 底 + mono 字体，质感最完整；代价是浅底提示在浅底界面上存在感略弱于深色胶囊。

方案 C

即时跟随（无键帽盒、贴光标、扫过即现）

延迟 120ms（同工具栏内移动到下一钮近似立即出）· 动效 80ms 纯淡入 · 定位 光标右下 12px 跟随 · 取舍：最快最跟手，密集工具栏逐个扫过时体验最顺；快捷键以"· Ctrl+Alt+B"弱化文字呈现，质感最简；代价是跟随光标会轻微遮挡视线焦点，长文本可读性弱于 A/B。
