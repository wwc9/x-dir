方案 C · 卡片流 Cards

条目即卡片——每条剪贴内容是一块独立软底卡片，内容边界清晰、图片有展示位，是最「现代化」的一档，信息密度略低于 A/B。
  • 条目卡片化：surface-2 软底 + 12px 圆角 + 8px 间距，条目之间靠留白分隔（无发丝线无斑马纹）。
  • 类型 = 淡染小 chip：文本/图片/文件用类型色族淡染角标置于卡片右上，颜色语义与文件图标族一致。
  • 图片条目横幅展示：卡内 64px 高横幅缩略（视觉占比显著提高，找图更快）；文字条目仍两行省略。
  • 过滤 chips 实心选中：accent 实底白字（当前是描边勾选式），更接近主流现代应用的过滤观感。
  • 选中/勾选 = accent 描边：1.5px inset accent 描边替代整行淡染，卡片轮廓更立体。
  • 页脚悬浮胶囊：计数 + 键帽 + 清空收进一条居中悬浮 bar，与卡片语言呼应。
