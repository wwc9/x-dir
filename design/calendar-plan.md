## 1. 一句话定位

在 X-Dir 内提供一张**月视图工作日历**：每个日期格子直接展示法定节假日 / 调休（班·休）/ 农历 / 节气 / 传统节日，点选格子即可**记录当天的工作条目**（一天多条，每条可标注状态：待办 / 执行中 / 已完成；本地持久化），并支持**按 月度 / 年度 / 自定义日期范围 导出工作 Markdown**；系统级快捷键（默认 `Ctrl+Alt+D`）任意界面唤起。

目标场景：审计/项目工作者的「今天干了啥」随手记（含顺手立的待办）→ 月末盘点、年终总结不再翻聊天记录和 Git log。

## 2. 调研结论（摘要）

### 2.1 同类产品交互惯例（优效日历 / DesktopCal / 滴答清单 / Day One / 飞书钉钉 / GitHub Wrapped 等）

采纳（P0，行业统一惯例）：
- **班/休角标**：格内日期旁小徽标，「休」红、「班」蓝（数据随国务院安排逐年更新，未发布年份优雅留白）。
- **农历小字**：公历数字下方灰色小字；传统节日/节气覆写农历文字并以色彩区分（节日红、节气蓝）。
- **今日高亮**：强调色实心圆标记 + 「今天」快速回位按钮。
- **周一起始**（中国月视图默认，首版不做设置项）；非本月日期降透明度置灰。
- **月导航**：‹ › 翻月 + 月份标题 + 「今天」。

采纳（P1，本功能差异化核心）：
- **格子内工作日志摘要**：有记录的日期在格内显示最多 2 条截断摘要（滴答清单「格子显示任务标题」形态），悬停 title 看全天全文，单击选中右侧详情逐条编辑（Day One 的「有内容着色 + 点击进详情」模板）；**双击格子 = 直接新增一条**（DesktopCal 最低摩擦惯例）。
- **工作条目状态（2026-11-13 用户反馈新增）**：每条工作标注 待办 / 执行中 / 已完成；格子内用**彩色小圆点**表达（绿 = 已完成、蓝 = 执行中、灰 = 待办，取 `--np-success` / `--np-accent` / `--np-muted`，不再新增徽标形态防「徽标泛滥」）；导出采用 **GitHub 任务清单语法**：已完成 = `- [x] 内容`、待办/执行中 = `- [ ] 内容（状态词）`，任意 Markdown 查看器可渲染勾选框。
- **法定节日名标红、周末数字弱化**（克制用色：周末不标红，仅 muted，避免满屏红——本项目单一强调色语言的取舍，与手机日历不同）。

规避（调研得出的坑）：不做黄历宜忌/天气/抢票等娱乐信息；徽标泛滥（只用「有无记录摘要 + 班休」两种标记，不按内容类型加图标）；格内只放截断摘要、全文进详情面板（渐进披露）；格内摘要只查询当前可见月份的数据（性能铁律 3 精神）。

**滴答清单专项二轮调研（2026-11-13，针对「格子内待办呈现」）**：月视图任务 = 色条无勾选框（勾选框为可选项/按住 Alt 临时显示）、**完成任务以变浅色保留显示**（显示设置可开关）、点格子空白即新建、拖拽改期、着色按清单/标签/优先级单维切换、月视图本身无统计（统计在摘要/成就页/年视图热力图）、方向键是翻页不是格间移动、**同日内不能手动调序是社区最大吐槽点**。借鉴采纳：完成淡化（不配「显示已完成」开关，记录型默认全显）；录入低摩擦（双击/hover ＋，替代其「点空白即新建」——保留单击选中语义）；轻量月度统计（本月完成 N 条）；过期未完成标红（详情面板维度）。明确不抄：重复任务/提醒/子任务/多清单体系/优先级四档/订阅同步/时间轴/看板（完整任务管理器负担）；其「格内禁调序」反着做——详情面板条目排序列 P2。

导出形态（GitHub Wrapped / RescueTime / Day One 导出 / Obsidian 周期笔记工作流，2026-11-13 用户反馈定案 = 三档范围取代「一键年度总结」）：**Markdown 导出为主**（统计头 + 按日期升序逐日小节 + 每条工作带任务清单状态语法 `- [x]`/`- [ ]`），统计数字（记录天数 / 条目数 / 状态分布）做预览；热力图/年视图导出图片列为远期 P2，首版不做。

### 2.2 数据源选型（离线优先）

| 项 | 选型 | 理由 |
|---|---|---|
| 法定节假日 + 调休班休 | **holiday-cn 按年 JSON 随应用打包**（2024–2027 共 4 个文件，单年 ~5KB；MIT） | 离线可用、零第三方运行时依赖；2026/2027 数据均已就绪（2027 安排 2026-11-05 发布，holiday-cn 当天跟进）；`{date, name, isOffDay}` 结构与「班/休」需求零转换；数据更新随应用发版走（应用已有 updater 通道，零额外基建） |
| 农历 / 节气 / 干支生肖 | **solarlunar 3.1（ISC，gzip 3.6KB，1900–2100 纯算法）** | 纯算法任何年份可用；体积仅 lunar-typescript 的 1/28；ISC 已有白名单先例（lucide-react ISC，opensource.md §台账）。传统节日（春节/元宵/端午/七夕/中秋/重阳/腊八/除夕）+ 公历纪念日（妇女节/青年节/儿童节/建军节/教师节/国家公祭日）自建 ~20 行常量表，不依赖库 |
| 日期月网格运算 | **原生 Date 自研纯函数 `lib/calendar.ts`**（不引入 dayjs） | 月矩阵/周起始/格式化是几十行可单测纯函数；项目零日期库现状维持，新增依赖只剩 solarlunar 一个 |

明确排除：timor.tech 在线 API（站点 CC BY-NC-SA + 数据许可不明 + 无 SLA 曾被打挂，与离线优先冲突）；chinese-days/chinese-workday（覆盖口径窄、与上述组合重叠）；lunar-typescript（MIT 备选，若 solarlunar 有边界 bug 再升级，代价 ~100KB gzip）。

注意两条数据口径：① 班/休判断**以 holiday-cn JSON 为唯一事实源**（solarlunar 若自带节假日数据一律不用，防双源冲突）；② 次年安排每年 11 月上中旬发布 → 数据文件头注释记录 papers 出处与抓取 commit，发版前人工刷新（首版不做应用内在线刷新，列为可选增强）。

## 3. 功能范围

### 3.1 首版（v1）做

1. **月视图**：6×7 网格、周一起始；**首行单行收纳日期基本信息**（2026-11-13 用户反馈定案）= 公历日（今日 accent 实心圆）+ 农历/节日副标题（法定节日红 / 传统节日红 / 节气蓝 / 常规农历灰）+ 班休徽标（休红·班蓝，右端）；其下为工作条目摘要（最多 2 行，更多以「… 还有 N 条」省略行示意——2026-11-13 用户反馈；每条前置 3×11px 状态竖条：绿=已完成 / 蓝=执行中 / 灰=待办，同日反馈要求状态标识明显）；非本月置灰。
2. **当日工作条目**：一天可记多条，每条 = 多行纯文本 + 状态（待办 / 执行中 / 已完成，三态 Seg；新建默认「已完成」，可改默认）。单击选中 → 右侧详情面板逐条增删改（输入自动保存 800ms 防抖 + 「已保存 HH:mm」回执；条目悬停浮出删除钮；**已完成条目文字淡化**——滴答清单惯例，完成不失信息密度）；**双击格子 = 新增一条并聚焦；悬停格子右下角浮现「＋」快记角标**（点击同效）；条目行右键 = 轻菜单（三态切换 / 删除，复用 `useUi.openMenu`）；**早于今天且未完成的条目在详情面板文字转 danger 并附「已过期」chip**（格子内不变色，防整月泛红）；一天内全部条目清空即删除该日。
3. **详情面板**：日期全称（2026年10月14日 · 星期三）+ 农历行（八月廿九 · 丙午马年）+ 假日状态 chip（国庆节·休 / 调休·班 / 工作日 / 周末）+ 当日条目列表 + 页脚统计（条数/字数 + 「本月已记录 N 天 · 完成 M 条」）。
4. **月导航**：‹ › / 「今天」/ Esc 关页；方向键在格间移动、Enter 新增条目（页内键盘，清单入 shortcuts.ts）。
5. **工作导出（三档范围，2026-11-13 用户反馈定案）**：「导出」按钮 → 对话框 = 范围 Seg（**月度 / 年度 / 自定义**）+ 对应范围控件（月度 = 年月步进器；年度 = 年 Seg；自定义 = 起/止日期输入，`yyyy-MM-dd` 内联校验）+ 统计预览（记录天数 / 条目数 / 已完成 / 执行中 / 待办）→ 原生保存框导出 Markdown（默认名 `工作日志-2026-11.md` / `工作日志-2026.md` / `工作日志-20261101-20261130.md`，默认目录 = 文档）。内容结构 = 统计头 → 按日期升序逐日小节（`## 11月13日 星期五 · 工作日`，节假日日带标注）→ 逐条工作带任务清单状态语法；范围外无记录日期不占篇幅；旁写 available_name 防覆盖。
6. **快捷键激活**：系统级热键（默认 `Ctrl+Alt+D`，可录制可关闭）→ 聚焦主窗口并打开日历页；顶栏模式组新增日历按钮（active 态、再点即关）。
7. **设置**：设置面板新增「日历」分页 = 启用开关 + 热键录制（HotkeyRecorder 复用）+ 显示农历开关（默认开）+ 数据说明行。
8. **离线数据覆盖 2024–2027**；无数据年份（2028+）格子正常渲染农历/节气（纯算法），班休留白并在详情面板提示「暂无官方安排」。

### 3.2 不做（防范围蔓延）

- 日程安排/提醒/重复事件/子任务/多清单与标签体系/优先级档位（与滴答清单等专用品划清边界——本功能只做「事后记录 + 轻待办」，一个状态字段就够）
- 第三方日历订阅与双向同步
- 黄历宜忌、天气、星座
- 多端同步、账号、云备份（数据文件随 export_config 导入导出已够便携）
- 年视图 / 热力图 / 导出图片（P2 候选，见 §8 决策点）
- 富文本（纯文本多行即可，导出是 Markdown 不是日记书）

## 4. 界面与交互设计（详见预览 HTML）

**承载 = 主窗口整页**（方案 A，推荐）：占满顶栏以下区域替换侧栏+窗格区，与全盘搜索页/定制页同构（`np-menupage` 壳：返回 pill + 标题 + 右侧工具行）；整页互斥（打开即关全盘搜索/定制页）；Esc 关闭（输入框内先失焦）。理由：REQUIREMENTS §2 单窗口哲学（功能专用窗口仅限「主窗口内无法实现的系统级 UI」——剪贴板浮窗因跨应用粘贴回贴成立，日历不需要覆盖层）；编辑与总结导出需要完整空间；零 Rust 窗口生命周期复杂度（无停靠/失焦看门狗）。

布局：头部行（返回 + 「工作日历」标题 + ‹ 年月 › + 今天 + 导出）→ 主体双栏 = 左日历卡（弹性）+ 右详情卡（~300px 定宽，窄窗折行到下方）。

格子信息层级（严格字号/色彩分层防过载）：**首行单行收纳日期信息** = 公历日 13px fg（今日 accent 实心圆）+ 农历/节日副标题 11px（法定·传统节日 = danger 红 / 节气 = accent 蓝 / 农历 = muted）+ 班休徽标 10px pill 右端（休 = danger 实底白字、班 = accent 实底白字）> 其下条目摘要 11px muted（≤2 行 + 「… 还有 N 条」省略行），每条前置 3×11px 状态竖条（已完成 = `--np-success` 绿、执行中 = accent 蓝、待办 = muted 淡灰——竖条比圆点明显，且与剪贴板行「左缘类型色条」语言同源）。选中格 = `--np-sel` 淡染 + accent 1px 描边（与行选中同语言）；今日 = accent 实心圆白字。

详情卡（右栏）自上而下：日期行 → 农历行 → 假日 chip 行 → **当日条目列表**（每条 = surface-2 凹陷卡：首行 状态三态 Seg（待办/执行中/已完成，chip 无描边口径）+ 悬停删除钮，次行透明多行输入自动保存）→ 「＋ 添加一条」虚线钮 → 页脚统计。双击格子 = 新增条目并聚焦。

导出对话框（np-dialog 三段式，§4.7/§4.9）：标题「导出工作记录」→ 双列参数行（范围 Seg 三档 + 对应控件行：月度 = 年月步进器 / 年度 = 年 Seg / 自定义 = 起·止输入框 `yyyy-MM-dd` 内联校验）→ 统计面板（记录天数 / 条目数 / 已完成 / 执行中 / 待办，随范围实时计算）→ `np-dialog-note` 左竖线说明（内容结构 + 输出预览行）→ Footer（取消 + 导出 Markdown accent 主操作）。

键盘（页内）：`↑↓←→` 移动选中日、`Enter` 新增条目并聚焦、`Esc` 条目内失焦→关页、`‹ ›` 等价 `PageUp/PageDown` 翻月、`T` 回今天。

数据量极小（42 格 + 单月记录），不触发三条铁律的列表/缓存条款；格内摘要只查当月（worklog_get_month 单次 IPC）；worklog.json 全量重写 ~<100KB 量级（数年使用），800ms 防抖合并连续输入。内存增量忽略不计（solarlunar 数据表 ~几十 KB JS 堆）。
