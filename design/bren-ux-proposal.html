批量重命名 · 易用性优化方案（任务向导化）

功能不变，把「搭规则」变成「选任务」：普通用户点常用任务一键起步，每条规则自带人话效果说明，预览高亮改动片段，错误说人话。
  • ①常用任务一键起步：预览区顶部新增任务 chips（去空格 / 批量编号 / 加日期 / 转小写 / 换扩展名）——点击生成整条规则链，可在卡上继续微调；高级用户仍可「＋添加规则」从零搭建。
  • ②规则卡自带人话效果行：每张卡底部用一句话说明这条规则会做什么（「把『_old』删除（所有出现）」），鼠标悬停参数即所见即所得。
  • ③作用域口语化 + 副标题：主名/整名/扩展名 → 「只改主名（保留 .txt 扩展名）」「整个名称（含扩展名）」「只改扩展名」，下拉每项带副标题解释。
  • ④预览 diff 高亮：新名里实际被改动的片段用 accent 底色标出——一眼看到「改了哪几个字」，而不是整行变蓝。
  • ⑤错误说人话：「目标重名」→「改完后会与第 2 行重名」；「名称非法」→「含有 Windows 不允许的字符 ?」（错误行内联小标签）。
  • ⑥正则不吓人：正则模式旁挂常用示例速插（去空格 / 去括号内容 / 去序号前缀），点即填入；非法时红字直接给修正示例。
  • ⑦空态即模板库：没加规则时显示 4 个模板按钮（批量编号 / 去空格 / 加日期前缀 / 转小写），点即生成规则链。
