方案 C「霜」亚克力玻璃

Win11 Fluent 气质：半透明 blur 底让菜单「浮」于内容上，边界靠内高光而非描边。

  • backdrop blur 22px + 饱和度提升，透而不乱
  • 悬停三联：玻璃高光条 + accent 左指示条 + 文字不变色
  • 左指示条：3px accent 圆角短条悬停浮现，位置感强
  • 氛围背景：本稿用彩色光斑演示 blur 效果，实装后在文件列表上同样成立
    • 取舍：backdrop-filter 有合成器开销（WebView2 GPU 良好）；深浅两套 glass token 需入 index.css
