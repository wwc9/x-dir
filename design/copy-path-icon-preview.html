「复制路径」图标方案预览

候选均来自 lucide（strokeWidth 2，与全库同源）。每张卡片：大图 + 尺寸档（12/14/16/20 = xs/sm/md/lg）→ 功能库胶囊（14px）→ 右键菜单邻居排（16px，检验与剪切/复制/粘贴/复制名称的区分度）。

现状 · ClipboardCopy lucide/clipboard-copy

剪贴板家族（ClipboardPaste / ClipboardList）已有两员，ClipboardCopy 与它们首部图形几乎同构；且它表达的是「剪贴板」而非「路径」，功能库里三枚同族图标靠文字才能分清。

方案 A · Link lucide/link

推荐
「路径 = 定位链接」的通感隐喻（地址栏 / 复制链接同款心智），斜向双环在 14px 依然清晰；与相邻的剪刀、双层方块、书写板、字母 T 全无同族风险。

方案 B · Route lucide/route

「路径」的直白象形：起点 → 折线路径 → 终点。全功能库唯一一块路线图形，辨识度最高；代价是隐喻偏「导航路线」，与剪贴板动作的关联要靠文字补足。

方案 C · FileSymlink lucide/file-symlink

「文件 + 快捷方式箭头」，最贴 Windows 资源管理器「复制文件地址」的既有心智；缺点是与库内文件族图标（FileText / FilePlus…）共享文件轮廓，且 14px 下折线箭头偏密。
