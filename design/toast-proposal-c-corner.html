▸ 悬停任一通知卡 = 暂停其倒计时；点击卡片空白处 = 消去；「详情」展开完整清单（多失败项逐条列出）；堆栈上限 3 条，溢出折叠为「还有 N 条」。
  • 堆栈规则：新通知顶部插入（120ms 滑入），同屏最多 3 条 + 折叠计数；错误常驻可固定，成功类 4s 自动退场。
  • 多失败项：这是三案中唯一能逐条列出完整失败清单的形态（展开后逐行编号 + 原因），「复制清单」一键带走。
  • 岛的去留：顶栏岛回归默认态（路径 + 已选 N 项）与任务进度；回执类全部退场——岛更安静，但短回执（已复制 N 项）也失去顶栏轻提示的位置感。
  • 权衡：视觉重心移到右下角，与「灵动岛居中播报」的既有心智冲突最大；需要处理与剪贴板浮窗（右下常驻）的位置避让。
