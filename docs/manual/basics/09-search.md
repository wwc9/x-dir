# 09 · 全盘搜索

顶栏「全盘搜索」按钮或 `Ctrl+Shift+F` 打开整页搜索。

![全盘搜索结果与内嵌预览](../images/gsearch-page.png)

## 三种工作方式

| 模式 | 说明 |
|---|---|
| NTFS 索引（推荐） | 状态条打开「常驻开关」→ 引导提权建索引 → USN 日志增量维护；458 万条目中文子串查询约 0.3s |
| 无索引扫描 | 未建索引时自动回落多线程遍历，流式出结果、可取消 |
| 索引状态 | 状态条左端显示 dot + 阶段（off/starting/building/ready/error），开关打开即弹逐卷进度 |

## 查询语法（对齐 Everything）

| 语法 | 示例 | 含义 |
|---|---|---|
| `ext:` | `ext:jpg;png` | 扩展名过滤（`;` 或、前导点可省）；`!` 取反 |
| `size:` | `size:>100mb`、`size:1k..5m` | 体积（`>` `>=` `<` `<=` 精确值或 A..B 区间，单位 b~tb） |
| `dm:` | `dm:today`、`dm:thisweek`、`dm:2026-11` | 修改时间（today/yesterday/thisweek/last<N>days/日期，支持比较符与区间） |
| `!` | `!备份` | 排除词 |
| `"…"` | `"季度 报告"` | 含空格的短语字面匹配 |

中文支持**拼音首字母与全拼**（如 `kxxz` 命中「可行性研究报告」），命中汉字高亮。

## 控制条与结果

- 单行控制条：搜索框 → 类型（全部/文件/文件夹 + 常用类型预设）→ 结果过滤 → 上限 → 预览开关（驻右）；
- **结果过滤**：右侧输入框对已加载结果按名称/拼音再次收窄，状态条回显「过滤后 N/M」；
- 列头点击排序（名称/位置/大小/修改时间）；窄面板自动隐藏修改时间列；
- 多选：`Ctrl` 翻选 / `Shift` 范围 / `Ctrl+A` 全选；选中后右键弹出批量菜单（复制完整路径 / 复制·移动到窗格 / 删除到回收站）；
- `Ctrl+Enter` 打开所在文件夹；`Enter` 打开文件；`Esc` 先清多选再关页面。
