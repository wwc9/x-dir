# 文件 · 复制路径与名称

把选中项的路径/名称按各种格式复制到剪贴板（配合剪贴板历史回看）。

## 入口

选中条目 → 右键 →「复制路径 / 复制路径 ▸ / 复制名称 / 复制名称（无扩展名）」。

## 变体

| 功能 | 复制内容示例 |
|---|---|
| 复制路径 | `E:\xdir-demo\01 项目资料\项目预算表.xlsx`（多选多行） |
| 复制路径 ▸ 正斜杠 | `E:/xdir-demo/01 项目资料/项目预算表.xlsx` |
| 复制路径 ▸ 带引号 | `"E:\xdir-demo\01 项目资料\项目预算表.xlsx"`（带空格路径贴进命令行/文档必备） |
| 复制路径 ▸ 扩展长路径 | `\\?\E:\...`（超长路径，资源管理器 260 字符限制场景） |
| 复制路径 ▸ 相对路径 | 相对当前文件夹的路径 |
| 复制路径 ▸ 所在文件夹 | 只复制父目录路径 |
| 复制名称 | `项目预算表.xlsx` |
| 复制名称（无扩展名） | `项目预算表` |

## 注意

- 多选时逐行复制（顺序 = 选中顺序）；
- 复制结果自动进入[剪贴板历史](../../basics/11-clipboard.md)，随时回捞；
- 把功能拖到**窗格工具栏**后，一键复制当前路径更顺手（定制页拖入「复制路径」）。
