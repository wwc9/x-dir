# 办公 · Excel 拆分

一份工作簿按四种方式拆成多份文件，**保真格式**。

![Excel 拆分对话框](../../images/xlsx-split.png)

## 入口

选中 **1 个工作簿**（xlsx/xlsm/xls/xlsb/ods）→ 右键 →「Excel 拆分」。

## 参数

| 模式 | 说明 |
|---|---|
| 按工作表 | 每个可见工作表一份文件（xlsx/xlsm 保真拆分：合并单元格/列宽/冻结/表头样式逐项迁移） |
| 按行数 | 每 N 行一份（自动分块） |
| 按列值 | 按某列的显示值分组（如按「区域」列拆成华东/华南/华北/西部四份；空值归「(空)」组） |
| 均分 N 份 | 平均拆成 N 份 |

- 表头行数：默认 1，0 = 不带表头；源前 N 行（含样式）复制到每份顶部；
- 输出到 `<原名>_拆分\` 子文件夹（可关直落源目录），重名 `(2)` 递增。

## 步骤

1. 选中工作簿 →「Excel 拆分」；
2. 选模式：按工作表 / 按列值（选依据列）/ 按行数 / 均分；
3. 执行后输出目录回执可直达：

![拆分输出](../../images/xlsx-split-done.png)

## 输出与注意

- 强制单文件：多选时工具栏/菜单条件不满足（执行端兜底提示）；
- 护栏：最多 500 份 / 200 组 / 200 份，防误操作拖垮磁盘；
- 日期列拆分后仍是真实日期值（不会变字符串）。
