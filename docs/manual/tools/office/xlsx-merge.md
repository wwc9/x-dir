# 办公 · Excel 合并

多工作簿合并为一份，双通道引擎：**保真合并**（样式/合并单元格/列宽/冻结窗格原样迁移）与**数据拼接**。

![Excel 合并对话框](../../images/xlsx-merge.png)

## 入口

选中 **≥2 个工作簿**（xlsx/xlsm/xls/xlsb/ods）→ 右键 →「Excel 合并」。

## 参数

| 参数 | 说明 |
|---|---|
| 方式 | **分表保留**：每个源文件作为独立工作表（保真通道，跨簿克隆工作表）/ **纵向拼接**：全部数据接成一列列长表 |
| 工作表范围 | 仅可见表 / 含隐藏表 |
| 表名规则 | 智能（仅表名/仅文件名自动判断）/ 仅表名 / 仅文件名 |
| 表头行数 | 拼接模式有效（默认 1；0 = 无表头全部按数据） |
| 去重复表头 | 后续文件前 N 行与首文件完全相同时跳过 |
| 来源列 | 拼接模式可加「文件名」或「文件名·表」列标记数据来源 |

## 步骤

1. 按顺序选中 1/2/3 月销售明细；
2. 右键 →「Excel 合并」，选「分表保留」或「纵向拼接」；
3. 确认参数 →「合并」，输出 `合并表格.xlsx`。

## 输出与注意

- 保真通道：样式、合并单元格、列宽、冻结窗格、图表、图片原样迁移（xlsx/xlsm 源）；
- xls/xlsb/ods 走数据通道（保值不保样式）；
- 输出旁写、绝不覆盖；**日期/数值类型逐格保留**，不会变成文本。
